# Migration Checklist（本仓库）

## 变更设计
- [ ] 变更类型明确（新表/字段/索引/回填）
- [ ] 文件命名清晰且可读
- [ ] 是否需要按专题目录归档已确认

## up/down 对称性
- [ ] `up()` 完整实现目标变更
- [ ] `down()` 可安全回滚当前变更
- [ ] 索引名、字段名、表名前后一致

## 执行与发布
- [ ] 已规划 `--path` 指定执行
- [ ] 已确认环境与分支对应（local/tests/production）
- [ ] 已评估线上锁表与执行窗口
- [ ] 已评估代码发布与 migration 先后顺序

## 风险控制
- [ ] 新字段默认值/可空策略合理
- [ ] 高风险删除操作有分阶段方案
- [ ] 数据回填策略可重跑、可回滚
