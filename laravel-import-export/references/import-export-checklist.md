# Import/Export Checklist（本仓库）

## 导入
- [ ] 参数校验完整（业务标识、文件路径、模式）
- [ ] 字段映射显式定义（title_maps）
- [ ] 使用 `getResourceData()` 或 `chunkParseExcel()` 处理文件
- [ ] `getResourceData()` 传参路径语义已确认（resource 相对路径 / 绝对路径）
- [ ] 大文件分批处理，避免内存爆涨
- [ ] 导入过程有进度输出（如 `cmd_progress_bar`）
- [ ] 行级错误可定位（行号+原因）
- [ ] 写库具备事务与幂等策略

## 导出
- [ ] 筛选条件固化并可追溯
- [ ] 大导出采用异步任务
- [ ] 状态流转清晰（待处理/处理中/成功/失败）
- [ ] Job 失败路径可回写错误原因（`failed()`）
- [ ] 失败支持人工重试
- [ ] 敏感字段权限与脱敏已评估

## 命令与任务联动
- [ ] 导出命令先校验任务状态，再触发导出
- [ ] 导入/导出命令仅做编排，核心逻辑下沉 Business/Job
- [ ] 失败回写信息可定位业务主键或任务编号
